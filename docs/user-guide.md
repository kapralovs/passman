# Руководство пользователя Passman

## Введение

Passman — это консольное приложение для безопасного хранения и управления паролями. Все данные хранятся локально и зашифрованы с использованием AES-256-CBC.

## Установка

### Требования
- Go 1.23+
- Linux/macOS (Windows через WSL)

### Установка из исходников
```bash
git clone https://github.com/kapralovs/passman.git
cd passman
make build
```

После сборки в текущей директории появится файл `passman`.

## Первый запуск

### Шаг 1: Инициализация
```bash
./passman init
```
Создаёт файл `config.json` с криптографическим ключом шифрования.

### Шаг 2: Регистрация
```bash
./passman signup --username=ваше_имя
```
Введите мастер-пароль. Он будет хэширован и сохранён.

### Шаг 3: Вход
```bash
./passman login
```
Введите мастер-пароль для начала сессии.

### Шаг 4: Добавление пароля
```bash
./passman add --service=github --login=user@email.com --password=MySecret123
```

### Шаг 5: Получение пароля
```bash
./passman get --service=github
```
Пароль выводится в терминал.

## Команды

### init
Инициализирует конфигурацию. Выполняется один раз.

```bash
./passman init
```

### signup
Регистрирует нового пользователя.

```bash
./passman signup --username=имя
```

### login
Вход в систему. Требует ввода мастер-пароля.

```bash
./passman login
```

### add
Добавляет новую запись пароля.

```bash
./passman add --service=сервис --login=логин --password=пароль
```

**Флаги:**
- `--service` — название сервиса (обязательный)
- `--login` — логин/email (обязательный)
- `--password` — пароль (обязательный)

### update
Обновляет существующую запись.

```bash
./passman update --service=github --login=newuser --password=newpass
```

### get
Выводит расшифрованный пароль.

```bash
./passman get --service=github
```

### help
Показывает справку по всем командам.

```bash
./passman help
```

## Управление сессиями

После входа сессия действует ограниченное время (по умолчанию 30 секунд). По истечении нужно выполнить `login` заново.

## Хранение данных

Все файлы хранятся в текущей директории:

| Файл | Описание |
|------|----------|
| `config.json` | Ключ шифрования и настройки сессии |
| `session.json` | Текущая сессия (имя, время входа) |
| `имя_vault.json` | Зашифрованные пароли пользователя |

Файлы имеют права доступа `0600` (только владелец).

## FAQ

### Где хранятся мои пароли?
Локально в файле `имя_vault.json` в зашифрованном виде.

### Что будет, если я забуду мастер-пароль?
Восстановление невозможно. Пароль хэшируется и не может быть восстановлен.

### Можно ли использовать на Windows?
Через WSL (Windows Subsystem for Linux).

### Безопасно ли это?
Данные зашифрованы AES-256-CBC. Однако для production рекомендуется использовать `bcrypt` вместо SHA-256 для хеширования мастер-пароля.
