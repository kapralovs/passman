# Passman

Безопасный CLI-менеджер паролей с локальным AES-256 шифрованием.

## Возможности
- 🔐 Шифрование паролей AES-256-CBC со случайным IV для каждой записи
- 🔑 Хеширование мастер-пароля через SHA-256
- ⏱️ Управление сессиями с настраиваемым TTL
- 📁 Локальное JSON-хранилище с правами доступа `0600`
- 🛡️ Безопасный ввод паролей через терминал

## Быстрый старт

### Требования
- Go 1.23+

### Сборка
```bash
git clone https://github.com/kapralovs/passman.git
cd passman
make build
```

### Базовый рабочий процесс
```bash
./passman init                  # Инициализация конфигурации
./passman signup --username=you # Регистрация
./passman login                 # Вход (ввод мастер-пароля)
./passman add --service=github --login=user --password=pass
./passman get --service=github  # Получение пароля
```

## Команды
| Команда | Описание |
|---------|----------|
| `init` | Создать конфигурацию с ключом шифрования |
| `signup --username=U` | Зарегистрировать пользователя |
| `login` | Аутентификация мастер-паролем |
| `add --service=S --login=L --password=P` | Добавить запись |
| `update --service=S --login=L --password=P` | Обновить запись |
| `get --service=S` | Получить расшифрованный пароль |
| `help` | Показать справку |

## Безопасность
- Пароли шифруются AES-256-CBC + случайный IV для каждой записи
- Мастер-пароль хэшируется (SHA-256), не хранится в открытом виде
- Файлы данных используют права `0600`
- ⚠️ **Важно**: Для хеширования мастер-пароля используется SHA-256 без соли. Для production рекомендуется миграция на `bcrypt` или `scrypt`.
